# 02. Phase 0: 基盤・マスター・取り込み

## 目的

後続フェーズの計算を正しく行うため、商品・原料・資材・作業場所・従業員・シフト・単価を一元管理する。

## 実装対象

### 基盤

- Webアプリケーションの初期構築
- 認証/権限
- DBマイグレーション
- 管理画面の土台
- 監査ログ
- CSV/Excel取り込み・エクスポートの基礎

### マスター

| マスター | 主な項目 |
|---|---|
| 商品マスター | 商品番号、正式商品名、別名、入り数g、入数、商品区分、受注生産/在庫生産区分、標準作業場所、請求対象フラグ |
| 商品BOM/レシピ | 商品、原料、資材、使用量、単位、ロス率、ミックス比率 |
| 原料マスター | 原料番号、正式名称、単位、標準単価、仕入先、リードタイム、賞味期限管理有無 |
| 資材マスター | 資材番号、正式名称、種類、単位、標準単価、仕入先、リードタイム |
| 手間賃/請求単価 | 商品、単価、単位、適用開始日、適用終了日、請求対象 |
| 生産能力マスター | 商品、作業場所、1時間1人あたり生産量、標準人数、備考 |
| 作業場所マスター | 名称、種別、表示順、設備、稼働時間、外注先フラグ |
| 従業員マスター | 氏名、所属、勤務可能時間、雇用区分、有効/無効 |
| シフトマスター | 日付、従業員、開始時刻、終了時刻、休憩、仮/確定 |
| 仕入先マスター | 仕入先名、連絡先、発注単位、締め情報 |
| 請求/伝票連携マスター | 外部システム商品コード、CSV項目、固定請求単価、請求先 |

## 取り込み方針

初期は既存Excelを完全自動解析する必要はない。マスター移行用CSVを用意し、手動補正を前提に登録できるようにする。

ただし商品名・商品番号は最重要である。文字起こし上でも「パソコンの正式な登録名」「商品ナンバー」が重要視されているため、正式名を主キー代わりにせず、必ず内部IDと商品番号を持つ。

## 権限

| 権限 | できること |
|---|---|
| 管理者 | 全マスター編集、ユーザー管理、確定取消、データ出力 |
| 製造管理 | 生産予定、割り振り、日報確認、在庫確認 |
| 現場入力 | 当日予定閲覧、日報実績入力 |
| 購買 | 発注候補確認、発注、入荷確定 |
| 経理/管理 | 手間賃、原価、請求出力 |
| 閲覧 | 各種一覧の閲覧のみ |

## 受け入れ条件

- 商品マスターを登録・編集・無効化できる。
- 原料/資材のBOMを登録できる。
- 1時間1人あたり生産量を商品別・作業場所別に登録できる。
- Excel由来のマスターをCSV等でインポートできる。
- 商品名表記揺れを別名として管理できる。
- 作業場所名は自由に追加・変更できる。
- マスター変更履歴が残る。
