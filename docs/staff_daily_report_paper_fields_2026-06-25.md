# スタッフ日報 紙日報項目追加メモ

## 追加内容

- スタッフ日報に人数日報欄を追加: 作業人数、シーラー、セット、備考。
- 原料行にロット番号と使用期限を追加。
- 紙の製造日報に合わせて、ピロ製造日、ピロ使用期限、包材ロット番号、固有記号、リボン交換時間、作業前チェック、金属探知機チェックを追加。
- 商品マスターに原料ロス率許容値を追加。既定は 5%。手詰めは 3%、NTSするめソーメン10g は 8% を商品ごとに設定する。
- スタッフ提出時、原料ロス率が商品別許容値を超える場合は提出不可にし、`ロス率異常のため、社員へ確認してから報告してください` を表示する。
