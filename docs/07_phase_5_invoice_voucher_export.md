# 07. Phase 5: 請求・売上伝票CSV/Excel出力

## 目的

日報実績から、売上伝票/請求書入力用のCSVまたはExcelを作成し、伝票システムへの二重入力を削減する。

文字起こしでは、FXクラウド等の伝票システムに1件ずつ入力している現状があり、CSV/Excel取り込みが可能であればまとめて出力したい要望がある。

## 前提

- 伝票システムへの直接API連携は初期対象外。
- CSV/Excel出力を初期ゴールにする。
- FXクラウド等の取り込み仕様が確認できたら、列定義を合わせる。

## 請求対象

基本的には、IBC側で作業した生産分をCase Company等へ請求する想定。

外注/AXで作った分は、AXからCaseへ直接行く等の扱いがあるため、社内請求対象から除外できるようにする。

## 出力項目案

| 項目 | 内容 |
|---|---|
| 伝票日付 | 日報日付または締め日 |
| 請求先コード | 請求先マスターから取得 |
| 請求先名 | 請求先マスターから取得 |
| 商品コード | 伝票システム上の商品コード |
| 商品名 | 伝票システム上の正式商品名 |
| 数量 | 実生産数量または請求単位換算数量 |
| 単位 | 袋/ケース等 |
| 単価 | 固定請求単価 |
| 金額 | 数量 × 単価 |
| 摘要 | 生産日、作業場所、備考等 |
| 外注除外フラグ | 請求対象外の判定 |

## 二重出力防止

- 出力済みフラグを持つ。
- 同じ日報を再出力する場合は再出力履歴を残す。
- 出力対象期間、請求先、外注除外の条件を明示する。

## 受け入れ条件

- 日報実績から請求候補一覧を作れる。
- 商品ごとの固定単価で金額を計算できる。
- 外注/AX分を除外できる。
- CSVまたはExcelを出力できる。
- 出力履歴が残る。
- 取り込み仕様が未確定でも、項目マッピングを管理画面で変更できる。
