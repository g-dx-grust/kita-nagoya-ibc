# 共通UIレビュー観点 2026-06-18

## 対象

本メモは、全体共通部分の初回UI調整を本番反映後にレビューするための確認リストです。

対象画面:

- ホーム
- 生産予定
- 発注候補
- 商品マスター
- 製品計画
- 月間予定
- 現場印刷

## 1. 左メニュー

確認すること:

- `日常業務`、`計画・確認`、`在庫・発注`、`マスター`、`出力` の分類で迷わず探せるか。
- 毎日使う画面が上に集まっているか。
- PC幅でスクロールせず主要メニューが見えるか。
- スマホのメニュー展開時も同じ順番で理解しやすいか。
- 折りたたみ状態でもアイコンの並びが不自然でないか。

判断したいこと:

- `シフト` は `日常業務` のままでよいか。
- `能力確認` は `計画・確認` でよいか、`マスター` 寄りにするか。
- `現場印刷` と `請求出力` は `出力` としてまとめてよいか。

## 2. 標準一覧テーブル

対象:

- 生産予定一覧
- 累積不足見込み
- 発注候補・発注状況
- 商品マスター

確認すること:

- ページ全体ではなく、表の中だけ横スクロールするか。
- 日付、時刻、数量、状態、操作列が折り返されず読めるか。
- 商品名、品目名、メモなど長い文字だけが自然に折り返されるか。
- 横スクロールした時に、必要な情報量が多すぎて操作しづらくないか。
- 商品マスターは列を残したままでよいか、主要列だけに絞るべきか。

判断したいこと:

- 商品マスターは次段階で `主要列だけ一覧 + 詳細画面で確認` に寄せるか。
- 操作列を右固定にする必要があるか。
- 生産予定一覧で商品列をさらに広げるべきか。

## 3. タイトル行と主要ボタン

対象:

- 生産予定
- 製品計画
- 月間予定
- 発注候補
- 現場印刷

確認すること:

- 画面名が左、主要ボタンが右に見えるか。
- 主要ボタンが多すぎて押しづらくないか。
- スマホ幅でボタンが縦に並んでも違和感がないか。
- 現場印刷の印刷ボタンはタイトル右にあった方が使いやすいか。

判断したいこと:

- `主要ボタンは最大2つまで` などのルールを作るか。
- 3つ以上ある画面は `その他` メニューへ逃がすか。
- `新規作成` は常に一番右、または一番強い色にするか。

## 4. 次にレビューする候補

共通部分の次は、以下の順がよいです。

1. 生産予定一覧
2. 生産予定新規登録
3. 当日割り当て
4. 日報
5. 商品マスター詳細

理由:

- 生産予定一覧は全業務の入口になりやすい。
- 新規登録は入力項目と計算結果の見せ方が重要。
- 当日割り当てと日報は現場利用に近く、タブレット操作の検討が必要。
