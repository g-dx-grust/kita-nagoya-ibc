# 14. 受け入れテスト

## Phase 0

### 商品マスター登録

- 商品番号、正式商品名、別名、受注生産/在庫生産区分を登録できる。
- 商品に原料BOMと資材BOMを設定できる。
- 1時間1人あたり生産量を作業場所別に設定できる。

期待結果: 生産予定登録時に商品を選ぶと、BOMと生産能力が参照される。

## Phase 1

### 数量固定モード

条件:

- 商品Aの1時間1人あたり生産量 = 100袋
- 数量 = 1000袋
- 人数 = 5人
- 開始 = 9:00
- 固定休憩時間帯 = 12:00〜13:00, 15:00〜15:15

期待結果:

- 所要時間 = 2時間
- 終了予定 = 11:00
- 17時超過なし

### 時間枠固定モード

条件:

- 商品Aの1時間1人あたり生産量 = 100袋
- 人数 = 5人
- 9:00〜17:00
- 固定休憩時間帯 = 12:00〜13:00, 15:00〜15:15

期待結果:

- 稼働時間 = 6.75時間
- 最大生産数量 = 3375袋

### 17時超過アラート

条件:

- 数量が多く、終了予定が19:15になる

期待結果:

- 17時超過アラートが出る。
- 残業135分と表示される。
- 翌営業日持ち越し候補が表示される。

### 原料不足アラート

条件:

- 生産予定により原料Xが50kg必要
- 現在庫20kg
- 確定入荷0kg

期待結果:

- 不足30kgと表示される。
- 発注候補に原料Xが出る。

### 未確定発注依存アラート

条件:

- 現在庫20kg
- 必要50kg
- 未確定入荷40kg

期待結果:

- 未確定込みでは足りるが、確定在庫では不足と表示される。
- 「未確定入荷依存」警告が出る。

## Phase 2

### 発注確定

- 発注候補から発注を作成する。
- ステータスを発注済み未確定にする。
- 確定数量と入荷予定日を入れて確定する。

期待結果:

- 確定入荷予定に反映される。
- 未確定アラートが消える。

## Phase 3

### 重複割り振り防止

- 従業員Aを9:00〜12:00で一般部屋に割り振る。
- 同じ時間帯に機械部屋へ割り振ろうとする。

期待結果:

- 重複警告が出て保存できない、または警告承認が必要。

### 合流候補

- 一般部屋が15:00で終了。
- 機械部屋が17:30までかかる。

期待結果:

- 15:00以降、一般部屋の人を機械部屋へ移動する候補が表示される。

## Phase 4

### 日報実績で在庫差し替え

条件:

- 予定原料使用量 = 180kg
- 実使用量 = 170kg

期待結果:

- 日報確定後、在庫は170kg消費として記録される。
- 予定との差異10kgが表示される。

## Phase 5

### 請求CSV出力

条件:

- 日報確定済み
- 商品Aの請求単価 = 12円
- 実生産数量 = 5640

期待結果:

- 金額 = 67,680円
- CSVに商品コード、商品名、数量、単価、金額が出る。
- 出力履歴が残る。
