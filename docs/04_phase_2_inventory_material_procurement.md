# 04. Phase 2: 原料・資材在庫 / 発注 / 入荷予定

## 目的

生産予定と日報実績に応じて、原料・資材の予定使用量、実使用量、在庫、発注候補、未確定発注を管理する。

## 在庫管理の考え方

在庫は単なる現在数だけでなく、台帳形式で管理する。

| 種別 | 内容 |
|---|---|
| 前月繰越/初期在庫 | 月初または導入時の在庫 |
| 予定使用 | 生産予定による予定消費。実在庫はまだ減らさない |
| 実使用 | 日報確定による実際の消費。実在庫を減らす |
| 入荷予定 | 発注により入る予定。未確定/確定を分ける |
| 入荷実績 | 実際に入荷し、在庫に加算したもの |
| 調整 | 棚卸差異、廃棄、移動等 |

## 原料在庫

必要機能:

- 原料別・日別在庫表示
- 使用予定量の自動反映
- 実使用量の反映
- 入荷予定、入荷確定
- 賞味期限管理
- 不足アラート
- 未確定入荷依存アラート
- 在庫移動/調整

## 資材在庫

必要機能:

- 資材別・日別在庫表示
- 袋、乾燥剤、段ボール等の使用予定量
- 入荷予定、入荷確定
- 不足アラート
- 商品BOMから必要資材を自動算出

## 発注管理

### 発注候補の生成

生産予定により不足が発生した場合、発注候補を生成する。

表示項目:

- 原料/資材
- 不足発生日
- 必要数量
- 現在在庫
- 予定使用量
- 確定入荷予定
- 未確定入荷予定
- 推奨発注数量
- 推奨発注日
- 仕入先
- リードタイム

### 発注ステータス

| ステータス | 意味 |
|---|---|
| 候補 | システムが不足から候補として出した状態 |
| 下書き | 担当者が数量や仕入先を調整中 |
| 発注済み未確定 | 発注したが数量/入荷日が確定していない |
| 確定 | 数量・入荷日が確定済み |
| 入荷済み | 入荷実績として在庫に反映済み |
| キャンセル | 発注取消 |

## 未確定発注アラート

文字起こしでは「発注したんだけど確定じゃないやつもアラート」「入ってくるかどうかわかんない」とある。したがって、未確定発注を在庫計算に含める場合も、画面上で明確に警告する。

## 受け入れ条件

- 生産予定確定時に、原料/資材の予定使用量が見える。
- 不足する原料/資材が発注候補に出る。
- 発注済み未確定の入荷は、確定入荷と別表示される。
- 入荷確定後、在庫見込みが更新される。
- 日報実績の実使用量で、予定使用量との差異が見える。
- 棚卸調整を登録できる。
