# 13. 業務ルール・計算式

## 生産時間

休憩は商品ごとではなく、1日の固定の作業不可時間帯として扱う。

```text
固定休憩時間帯 = 12:00〜13:00, 15:00〜15:15
```

```text
予定所要時間(h) = 生産数量 / (1時間1人あたり生産量 × 人数)
予定終了時刻 = 開始時刻から予定所要時間分の作業時間を積み上げる
              ただし固定休憩時間帯は作業時間に含めない
残業時間 = max(0, 予定終了時刻 - 基準終了時刻)
```

基準終了時刻は原則17:00。ただし作業場所や日付ごとに変更できる。

## 時間枠内の最大生産数量

```text
稼働時間(h) = 終了希望時刻 - 開始時刻 - 固定休憩時間帯との重複時間
最大生産数量 = 1時間1人あたり生産量 × 人数 × 稼働時間(h)
あふれ数量 = max(0, 要求数量 - 最大生産数量)
```

## 必要人数

```text
必要人数 = ceil(要求数量 / (1時間1人あたり生産量 × 稼働時間(h)))
```

## 原料使用量

BOMに基づく。

```text
予定原料使用量 = 生産数量 × 商品1単位あたり原料使用量 × (1 + ロス率)
実原料使用量 = 日報で入力された使用量
```

ミックス品は、BOMに複数原料と比率を持たせる。

## 資材使用量

```text
予定資材使用量 = 生産数量 × 商品1単位あたり資材使用量 × (1 + ロス率)
```

袋、乾燥剤、段ボール等を商品BOMで管理する。

## 在庫見込み

```text
確定在庫見込み = 現在庫 + 確定入荷予定 - 予定使用量
未確定込み在庫見込み = 現在庫 + 確定入荷予定 + 未確定入荷予定 - 予定使用量
```

確定在庫見込みがマイナスの場合は不足アラート。未確定込みなら足りる場合も「未確定入荷依存」アラートを出す。

## 日報確定時の在庫反映

- 予定使用量は予定引当として扱う。
- 日報確定時に実使用量を在庫台帳へ記録する。
- 実使用量が予定使用量と違う場合、差異を表示する。

## 原価

```text
原料原価 = 実原料使用量 × 原料単価スナップショット
資材原価 = 実資材使用量 × 資材単価スナップショット
作業費 = 実人数 × 実稼働時間 × 時給 または 実生産数量 × 手間賃単価
総原価 = 原料原価 + 資材原価 + 作業費
```

請求単価と実原価は別物として管理する。

## 受注生産と在庫生産

| 区分 | ルール |
|---|---|
| 受注生産 | 受注数量ぴったり作ることが多い。作り切り/使い切り扱い |
| 在庫生産 | 受注数だけでなく、過去需要や月間消化量から多めに作る場合がある |
| 両方 | 商品ごとに都度区分を選ぶ |

## 月間生産予測

原料発注を前月確定前に進められるよう、月間生産予定の初期予測は前々月前年比を使う。

```text
前々月前年比 = 今年前々月実績数量 / 前年前々月実績数量
当月予測生産数 = 前年対象月実績数量 × 前々月前年比
```

前年対象月、前年前月、前年前々月、今年前月、今年前々月は参考として表示する。ただし前月実績は締まっていない場合があるため、発注前の予測計算には必須としない。
在庫生産/両方の商品は標準ロットが設定されていればロット単位に切り上げる。受注生産は予測数量をそのまま扱う。

## 翌営業日持ち越し

17時までに終わらない場合、以下を選択できる。

- 残業する
- 翌営業日に持ち越す
- 数量を減らす
- 在庫が足りているため予定から外す
- 別作業場所/外注へ振る

## 発注

- 不足が発生したら発注候補を出す。
- 発注済み未確定は在庫として確定扱いしない。
- 確定した入荷だけを確定在庫見込みに含める。
- 入荷実績登録で在庫に加算する。

## 請求

```text
請求金額 = 実生産数量 × 商品別固定請求単価
```

外注/AX分は請求対象外にできる。
