# 09. 外注・AX・本社/拠点間在庫

## 背景

文字起こしでは、外注に振っている作業や、AX/パックスのような外部作業場所が存在する。暇な時は自社で作ることもあり、100%外注固定ではない。また、原料の一部は外注先側に置いて管理される場合がある。

## 基本方針

外注先は「4つ目の部署/作業場所」として扱えるようにする。ただし、社内の作業場所と違い、以下の差分を持つ。

- 社内請求対象外になる場合がある。
- 外注先在庫や預け在庫を持つ場合がある。
- 原料を外注先へ移動し、戻り予定日を管理する必要がある。
- 出荷は最終的に本体在庫/Case側から行われる可能性がある。

## 必要機能

- 外注先マスター
- 外注生産予定
- 外注戻り予定日
- 外注先へ渡した原料/資材の移動
- 外注先在庫/預け在庫
- 外注分の日報または入荷実績
- 請求対象/対象外の判定

## 初期スコープ

最初は北名古屋内の原料・資材・生産予定を優先する。外注先の詳細在庫は、Phase 2以降で最低限の管理から始める。

## 未確定事項

- 正式な外注先名（AX/アクス/パックス等）
- 外注先へ渡した原料の所有権と在庫計上方法
- 外注先が使った原料の実績取得方法
- 外注分を日報に含めるか、入荷実績だけにするか
- 外注分の請求除外ルール
