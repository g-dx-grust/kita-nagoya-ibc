# 03. Phase 1: 手動生産予定MVP

## 目的

現場が生産予定を手動で入力した時点で、作業時間、終了見込み、原料/資材使用量、手間賃、原価見込み、不足アラートを即座に確認できるようにする。

このフェーズでは、製品在庫クラウドから自動で生産予定を生成する機能は作らない。予定は人が入力する。

## 画面

### 生産予定一覧

- 月間表示
- 週間/日別表示
- 作業場所別表示
- 商品別検索
- 不足アラート絞り込み
- 17時超過/残業予定の絞り込み
- 仮予定/確定予定の切替

### 生産予定登録・編集

入力項目:

- 生産日
- 商品
- 生産区分: 在庫生産 / 受注生産 / 外注 / 試作 / その他
- 数量
- 数量単位: 袋、ケース、kg等
- 作業場所
- 開始時刻
- 終了希望時刻または終了基準時刻
- 作業人数
- 担当者メモ
- 仮/確定

休憩は商品ごとに入力しない。12:00〜13:00、15:00〜15:15を1日の固定休憩時間帯として扱い、その時間帯は作業不可とする。

自動計算項目:

- 予定終了時刻
- 予定稼働時間
- 1人時あたり生産量
- 予定原料使用量
- 予定資材使用量
- 予定手間賃
- 予定原料原価
- 予定資材原価
- 予定総原価
- 在庫不足有無
- 17時超過有無
- あふれ数量

## 3つの計算モード

文字起こしでは、数量・時間・人数の見方を複数パターンで求めている。Phase 1では以下の3モードを実装する。

### 1. 数量固定モード

「この数量を、この人数で作ると何時までかかるか」を計算する。

入力:

- 商品
- 数量
- 開始時刻
- 人数
- 作業場所

出力:

- 終了見込み
- 所要時間
- 17時超過有無
- 残業時間

### 2. 時間枠固定モード

「9時〜17時などの時間枠内で、この人数なら何個/何袋まで作れるか」を計算する。

入力:

- 商品
- 開始時刻
- 終了希望時刻
- 人数
- 作業場所

出力:

- 最大生産可能数量
- 要求数量との差分
- あふれ数量
- 翌営業日持ち越し候補

### 3. 人数調整モード

「この数量を17時までに終えるには何人必要か」「人数を増減すると終了時刻がどう変わるか」を計算する。

入力:

- 商品
- 数量
- 開始時刻
- 終了希望時刻
- 作業場所

出力:

- 必要人数
- 候補人数ごとの終了時刻
- 不足人数
- シフト上の利用可能人数との比較

## 計算式の基本

実装時は `docs/13_business_rules.md` の式に従う。

例:

```text
予定所要時間(h) = 生産数量 / (1時間1人あたり生産量 × 人数)
予定終了時刻 = 開始時刻から予定所要時間分の作業時間を積み上げる
              ただし固定休憩時間帯は作業時間に含めない
時間枠内最大数量 = 1時間1人あたり生産量 × 人数 × 稼働時間(h)
```

## アラート

- 17時超過
- 指定終了時刻超過
- 原料不足
- 資材不足
- 商品マスター未登録
- BOM未登録
- 生産能力未登録
- 発注済みだが未確定入荷でしか足りない
- 受注生産なのに予定数量と出荷数量が不一致の可能性

## 受け入れ条件

- 商品・数量・人数・開始時刻を入れると終了時刻が表示される。
- 17時を超える場合は警告が表示される。
- 終了希望時刻を入れると、その時間までに作れる数量とあふれ数量が表示される。
- 生産予定から原料/資材予定使用量が表示される。
- 原料/資材が不足する場合、不足数量と発注候補が表示される。
- 仮予定と確定予定を分けられる。
- 生産予定を確定しても、日報実績が入るまでは実在庫を減らさず、予定引当として扱う。
