# 06. Phase 4: 日報・実績反映・原価計算

## 目的

現場がタブレット等から日報実績を入力し、予定値を実績値へ置き換えて、在庫・原価・手間賃・請求用データへ反映する。

## 日報入力

入力項目:

- 生産日
- 生産予定ID
- 商品
- 作業場所
- 実開始時刻
- 実終了時刻
- 実休憩時間
- 実作業人数
- 実生産数量
- 実使用原料
- 実使用資材
- 廃棄/ロス
- 賞味期限/ロット
- 備考
- 入力者

## 実績反映

予定では180kg使用見込みだったが実際は170kgだった、というケースがある。日報確定時には、予定使用量ではなく実使用量を在庫・原価に反映する。

反映順序:

1. 日報下書き登録
2. 実績数量・実使用量入力
3. 差異確認
4. 日報確定
5. 在庫台帳へ実使用を記録
6. 原価・手間賃を再計算
7. 請求出力対象へ反映

## 原価計算

計算対象:

- 原料原価
- 資材原価
- 手間賃/作業費
- 実作業時間
- 1時間1人あたり実生産量
- 予定との差異

原料・資材単価は日報時点の適用単価を使う。単価変更があるため、過去日報の原価が後から変わらないよう、日報確定時にスナップショットを保持する。

## 手間賃

添付Excelには商品ごとの1袋手間賃がある。システムでは以下を分ける。

- 社内の実作業コスト: 人数 × 時間 × 時給等で計算可能
- 請求/売上用の固定単価: 商品ごとに決まる単価
- Excel上の1袋手間賃: 現行の計算基準として保持

## 受け入れ条件

- 生産予定から日報を作成できる。
- 日報で実生産数量、実使用原料、実使用資材を入力できる。
- 日報確定後、在庫が実績値で減る。
- 予定値と実績値の差異が見える。
- 1時間1人あたり生産量を自動計算できる。
- 原料原価・資材原価・手間賃を日報単位で表示できる。
- 日報確定後の修正は権限と履歴を必須にする。
